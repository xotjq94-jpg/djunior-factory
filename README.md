# 디주니어 자료 공장

설교문을 바탕으로 설교 이미지, 리마인드 영상, 교사용 공과를 만드는 Windows 앱입니다.

## 처음 설치하기

1. [최신 버전 받기](https://github.com/xotjq94-jpg/djunior-factory/releases/latest)를 엽니다.
2. `DJunior-Factory-Windows-v버전.zip` 파일을 내려받고 압축을 **모두** 풉니다.
3. 폴더 안의 **디주니어 자료 공장 실행.vbs**를 한 번 실행합니다.
4. 바탕화면에 생긴 **DJ 아이콘**으로 다음부터 실행합니다.

Windows 64비트용이며 Python·영상 변환 실행 환경이 포함되어 있습니다. AI 제작에는 이 PC의 Codex에서 ChatGPT 계정으로 로그인해야 합니다. 별도 API 키는 사용하지 않으며 계정의 이용 한도가 적용됩니다. 프로그램 설치와 업데이트 다운로드에는 GitHub 로그인이 필요하지 않습니다.

## 업데이트

v1.1.0부터 앱을 켤 때 새 버전을 확인합니다. 새 버전의 변경 내용을 읽고 **지금 업데이트** 또는 **나중에**를 선택하세요. **기본 설정 → 앱 업데이트**에서 직접 확인하거나 자동 확인을 끌 수도 있습니다.

자료 제작 중에는 업데이트를 시작하지 않습니다. 업데이트하면 앱을 다시 열며 저장된 원고·제작 기록·완성 파일·스타일 설정은 유지합니다. 저장하지 않은 입력은 먼저 보관하세요. 새 버전 시작에 실패하면 이전 프로그램으로 복구합니다.

v1.1.0보다 오래된 앱은 새 Windows ZIP으로 한 번 교체해야 합니다. 앱 종료 → 기존 폴더 백업 → 새 ZIP을 같은 프로그램 폴더에 덮어쓰기 순서로 진행하고, **factory_app/data 폴더를 삭제하지 마세요.**

`djunior-update.zip`과 `djunior-update.json`은 앱이 사용하는 업데이트 파일입니다. 처음 설치할 때는 Windows ZIP을 받으세요. 실행 환경이 바뀌는 큰 업데이트에서는 새 설치 파일이 필요할 수 있습니다.

## 자료 보관

이 저장소에는 프로그램 배포 파일만 있습니다. 사용자 원고, 제작 기록, 생성 결과물, 로그인 정보는 업로드하지 않습니다. 자료는 각 PC의 프로그램 폴더 `factory_app/data`에 보관하며 두 PC 사이의 자료 동기화 기능은 없습니다.

앱 소스는 Windows ZIP의 `factory_app`에 포함되어 있습니다. 포함된 Python·라이브러리의 라이선스 위치는 ZIP의 `라이선스 안내.txt`를 확인하세요.
